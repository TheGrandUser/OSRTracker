# Pages

## Main Page

Two states: 
- A welcome view that shows existing campaigns
- A campaign view that shows a summary of the current campaign: session tracks (with current session) and character list

## System Editor Page

Edit attribute names

Define classes (XP level requirements, key attributes)

## Character Roster Page

Shows a table of all characters and their statistics and allows editing and making new characters

## Active Session Track Page

Shows details/notes of the current session, the list of characters present

Table of the XP and treasure rewards

Session and Delve management

### Apply Session and Delve XP Dialog

Upon Session or Delve completion

Session Inputs: monsters, general XP, characters present
Delve Inputs: treasure, list by session of characters participating in the delve
Both inputs: class definitions for XP bonus

Delve XP application options:
- apply equal shares to all participating party members across all sessions of the delve
- apply shares proportional to the number of sessions where the character was present
- apply equal shares to party members who were present during or after acquiring the treasure
- apply shares proportional to the number of sessions where the character was present during and after the treasure was acquired

options for deceased characters
- marked as recovered
- qualify for XP gain (presuming raising spells, or XP applied to replacement character)
- Some way to link deceased characters to living characters if replaced in the dungeon so they count as one character for XP application?

XP calculation is fed into inputs for each character where the user adjust things
Perhaps in a table, with character Current/Next XP, XP awarded, resulting XP, character type (PC or henchmen), alive or dead, XP bonus

## Sessions x Characters XP Awards Page

Summary of XP acquired for each character for each session
